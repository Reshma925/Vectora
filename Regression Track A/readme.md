# Communities and Crime Regression Project

## Overview
This repository contains a machine learning project focused on predicting crime rates using the **Communities and Crime** dataset. The project explores various regression techniques to understand the socioeconomic and demographic factors that influence crime across different communities.

## Project Structure
The analysis is structured into several key stages:

- **Section A - Dataset & Exploratory Data Analysis (EDA):** Initial loading, data auditing, missing value analysis, and correlation profiling.
- **Section B - Preprocessing & Feature Engineering:** Data cleaning, outlier management, imputation, scaling, and engineering of composite indices (e.g., Socioeconomic Stress Index).
- **Section C - Advanced Regression Track:** Training and evaluating multiple regression models, including:
  - Linear, Ridge, Lasso, and ElasticNet Regression
  - Decision Trees and Random Forests
  - Gradient Boosting Regressor
  - Support Vector Regressor (SVR)
  - K-Nearest Neighbors

## Data
The dataset used in this project is based on US Census data, law enforcement data, and crime statistics.
